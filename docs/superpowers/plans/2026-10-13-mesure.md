# Mesure — plan d'implémentation

> Exécution inline, TDD à chaque tâche, relecture indépendante à la fin. Jeanne : « vas-y sans t'arrêter ».

**Spec :** `docs/superpowers/specs/2026-10-13-mesure-design.md`

## Contraintes globales

- Aucun texte en dur dans le JSX ; clés FR et EN (`mesure.*`) ensemble.
- `tsc` à zéro, suite verte, build OK. Migration générée, relue, appliquée sur dev seulement, additive.
- Aucun indicateur à zéro quand la donnée manque. Aucun appel IA sans données à commenter.
- Mesure jamais dans le contexte en mode tiers.

## Review Focus

1. Données absentes ou nulles (aucune dépense, zéro client) : indicateur null, jamais 0 ni Infinity.
2. Mois futur, mal formé ou d'un autre projet : refusé.
3. Import : séparateurs et décimales mal détectés qui décaleraient les montants (×1000, colonnes glissées).
4. Routine : pas de bilan payé deux fois pour les mêmes chiffres ; rappel sans appel IA.
5. Cadence mensuelle : 2 du mois, fins de mois et décembre → janvier.

## Tâches

1. Schéma, migration, stockage (+ reset, suppression de projet), cadence mensuelle.
2. Fonctions pures : catalogues, calculs, évolutions, validation, import, suggestion, contexte.
3. Routine de bilan (+ registre).
4. Routes (+ enregistrement) ; `Kpi.source` et `kpiAuto` dans les Fondations.
5. Contexte de Naya.
6. Interface : page, composants, locales, barre latérale ; affichage des KPI reliés dans les Fondations.
7. Vérification, relecture indépendante, corrections, fusion locale.
