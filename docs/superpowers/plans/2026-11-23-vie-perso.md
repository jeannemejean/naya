# Vie perso Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Option « Vie perso » : plan de repas de la semaine (foyer, batch, courses), activités perso, placées dans le planning hors heures de travail.

**Architecture:** Module pur `shared/vie-perso.ts` (types, zod, phase du cycle, marqueur de tâche perso) ; tables `vie_perso_*` (migration 0043) ; services `server/services/vie-perso/` (placement pur, consignes, génération via genererStructure, store, deps) ; routes `server/routes-vie-perso.ts` ; page client `/vie-perso`. Le moteur de travail ignore les tâches perso (et les compte comme occupées).

**Tech Stack:** Express, Drizzle/Neon, zod v4, vitest, React + react-query + i18next.

**Spec:** docs/superpowers/specs/2026-11-23-vie-perso-design.md

## Global Constraints
- Marqueur d'une tâche perso : `source === "vie_perso"` (pas de nouvelle colonne sur `tasks` ; voir Ruling 1). Toujours `schedulingMode: "fixed"`, date + heure, `projectId: null`, `type: "admin"`.
- Interrupteur : `VIE_PERSO_USERS` (ids séparés par des virgules).
- Défauts : soirs 18:30–22:00, week-end 09:00–20:00, déjeuner 12:00, dîner 19:30, batch dimanche 10:00 120 min, courses samedi 10:00 60 min.
- Textes générés : français, aucun tiret long ni demi-cadratin.
- Migration 0043 avant tout push sur main ; push et migration prod seulement avec l'accord de Jeanne.

## Review Focus
1. Une tâche perso ne doit jamais être déplacée, ramenée, archivée ou reprise par le moteur de travail (retasserJours, reprise, fil, allègement).
2. Une tâche perso dans la fenêtre de travail bloque son créneau pour les tâches de travail.
3. Re-valider un plan remplace les tâches perso non faites de ce plan, jamais les faites.
4. Exclusions alimentaires d'un membre jamais violées (consigne) ; plan invalide (zod) → erreur claire, pas d'écriture.
5. Utilisatrice sans l'option : toutes les routes `/api/vie-perso/*` répondent 404.
